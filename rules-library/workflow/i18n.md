# Internationalization (i18n)

## Adding User-Facing Text

Every user-visible string MUST exist in both locale files:
- `packages/i18n/src/locales/en/common.json`
- `packages/i18n/src/locales/he/common.json`

## Rules

1. **Never hardcode strings** in components — always use translation keys
2. **Add to both locales** simultaneously — never leave one empty
3. **Hebrew text** must be RTL-aware (see `workflow/rtl.md`)
4. **Key naming**: use dot-notation namespaces matching the feature area
   - `auth.login.title`, `search.filters.price`, `profile.edit.save`
5. **Plurals**: use ICU MessageFormat syntax where supported

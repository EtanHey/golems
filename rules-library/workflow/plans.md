# Plan-Driven Development

## Where Plans Live

- Project plans: `docs.local/plans/` (gitignored, local only)
- Naming: `YYYY-MM-DD-feature-name.md`

## Rules

1. **Read the plan first** before implementing any feature with an active plan
2. **Check Linear** for the project/issue linked to the plan
3. **Follow plan decisions** — don't re-decide things already decided
4. **Update the plan** when requirements change or decisions are made during implementation
5. **One plan per feature** — don't merge unrelated work into one plan

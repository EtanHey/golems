AI coding agents have amnesia.

Every time I start a new Claude Code session, it forgets:
- The architecture decision I made last week
- The debugging session that took 3 hours
- My preference for Bun over npm
- Why I chose SQLite over Postgres for that feature

After months of repeating myself, I built BrainLayer.

It indexes my Claude Code conversations into a local database with semantic search. 268K+ chunks from 2 years of coding sessions — every decision, every fix, every learning.

Now when I ask "how did I implement auth?" my agent actually knows. Under 100ms.

How it works:
- Indexes conversation transcripts automatically
- Hybrid search: vector embeddings + keyword
- 14 MCP tools that integrate with Claude Code, Cursor, VS Code
- LLM enrichment: auto-generates summaries, tags, importance
- 100% local. No cloud. No API keys. Your data stays yours.

I open-sourced it: link in comments.

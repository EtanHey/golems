# Night Shift

Manage Night Shift settings.

Arguments: $ARGUMENTS (optional: action — status, target [repo], run, history)

1. **status** (default) — Current target repo, last run, pending PRs
2. **target [repo]** — Set tonight's Night Shift target
3. **run** — Trigger Night Shift immediately
4. **history** — Recent Night Shift PRs and merge status

Rotation: Mon/Thu=songscript, Tue/Fri=zikaron, Wed/Sat/Sun=claude-golem

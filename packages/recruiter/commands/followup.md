# Follow-up Tracker

Check overdue follow-ups in the outreach pipeline.

1. Query outreach messages past their follow-up due date
2. Due dates: interview=3d, job=5d, urgent=1d, other=7d
3. Show each overdue item: contact, company, days overdue, original message
4. Suggest follow-up actions (re-send, different channel, mark as cold)

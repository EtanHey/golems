# Outreach Pipeline

Manage the outreach pipeline.

Arguments: $ARGUMENTS (optional: action — list, draft, send, stats)

1. **list** — Show pending outreach messages with status
2. **draft** — Generate a new outreach message for a target company/contact
3. **send** — Mark a draft as sent (tracking only — actual sending is manual)
4. **stats** — Show outreach funnel: contacts → sent → replies → interviews

Default action: list

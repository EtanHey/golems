# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/EtanHey/golems/security/advisories/new).
Include affected paths or versions, reproduction steps, impact, and any known
mitigations.

Do not open a public issue for an undisclosed vulnerability or include secrets,
tokens, personal data, or exploit details in public discussions.

For non-sensitive hardening suggestions, open a regular GitHub issue.

## Supported versions

Security fixes target the current `master` branch. This project does not
currently publish a separate long-term-support release line.

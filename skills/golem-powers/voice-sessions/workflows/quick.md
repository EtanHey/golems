# Quick Text Debrief

## When to Use
- voicelayer MCP not connected
- User is in a quiet environment / can't talk
- User just wants to dump info quickly

## Process

Ask these questions in chat (not voice). User types responses.

### Essential Questions (always ask)
1. Who + company + what type of conversation?
2. Top 3 things discussed?
3. What are the next steps?
4. Red flags? Gut feeling?

### If User Has Time (ask after essentials)
5. What questions did they ask?
6. What seemed to impress them?
7. Anything you wish you'd said differently?

## Output

Same Obsidian template as full debrief, but shorter entries.
Mark as `## Quick Debrief` in the header to distinguish from full voice debriefs.

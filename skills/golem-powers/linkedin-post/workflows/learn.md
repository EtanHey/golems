# Learn to Write LinkedIn Content

Structured learning path for writing tech content on LinkedIn. Not just "draft for me" — teaches you the WHY behind good posts so you internalize the patterns.

## Philosophy

Like interview practice (7 modes, Elo tracking), this is deliberate practice:
1. **Study** top performers (what works and why)
2. **Deconstruct** their posts against the 11 rules
3. **Practice** writing hooks, meat sections, CTAs separately
4. **Get feedback** on your drafts with specific rule citations
5. **Track progress** over time

## Learning Modules

### Module 1: Hook Writing (the hardest skill)

The hook is 80% of the battle. If they don't stop scrolling, nothing else matters.

**Exercise:** Write 5 hooks for the same topic. Score each:
- Does it create curiosity?
- Is it under 3 lines?
- Does it have a number, confession, or contrarian take?
- Would YOU stop scrolling?

**Hook patterns that work for tech:**

| Pattern | Example | Why it works |
|---------|---------|-------------|
| **Surprising number** | "238 jobs, zero API keys." | Specificity creates credibility |
| **Personal confession** | "I spent 6 months building something nobody asked for." | Vulnerability = relatability |
| **Contrarian take** | "RAG is dead. Here's what replaced it." | Challenges beliefs = must-read |
| **Before/After** | "3 months ago I was mass-applying to jobs. Now jobs come to me." | Transformation story |
| **Question** | "What if your AI assistant remembered every conversation?" | Invites mental engagement |

**Practice drill:** Pick any topic from your work this week. Write one hook in each pattern. Time yourself — 2 minutes per hook. Speed builds instinct.

### Module 2: The Meat (delivering value)

The meat is what gets saves. Save = 100 algorithm points.

**What makes content save-worthy:**
- Checklists ("10 things to check before deploying")
- Frameworks ("my 3-step process for X")
- Specific numbers ("reduced latency from 2s to 200ms by doing Y")
- Lessons learned ("3 mistakes I made building autonomous agents")

**Exercise:** Take something you built this week. Write it as:
1. A numbered list (5-7 points)
2. A before/after story
3. A "here's what I learned" reflection

Which version feels most save-worthy?

**Tech content golden rule:** Show the code/architecture, but explain the WHY. Developers save "why" posts, not "how" posts (they can Google the how).

### Module 3: CTA That Drives Discussion

Bad CTAs: "Follow me for more" / "Like if you agree"
Good CTAs: Open questions that people actually want to answer.

**CTA patterns for tech:**

| Pattern | Example |
|---------|---------|
| **Experience sharing** | "What's the weirdest bug you've spent a whole day on?" |
| **Opinion request** | "Do you think AI agents should have memory? Why or why not?" |
| **Challenge** | "Try this approach on your next project. Report back." |
| **Debate** | "Monorepo or polyrepo? I'll fight anyone who says polyrepo." |

**Exercise:** Write 3 CTAs for your last post topic. Ask: "Would I reply to this if I saw it on my feed?"

### Module 4: Voice and Authenticity

Your voice is your unfair advantage. Stock AI content is everywhere — people follow PEOPLE.

**Define your authentic voice markers:**
- Languages and code-switching preferences
- Preferred formality and sentence length
- Humor style
- Expected level of technical detail

**Exercise: Anti-corporate translation.** Take a generic LinkedIn post and rewrite it in your voice:

Generic: "We're excited to announce our latest innovation in AI-powered recruitment optimization."
Your voice: "Built a thing that finds jobs while I sleep. Here's how it works."

### Module 5: Deconstruct Top Performers

Find 3 posts this week with high engagement (100+ comments or 50+ saves). For each:

1. **Count:** Words, sentences, lines before "See more"
2. **Structure:** Where's the hook? The meat? The CTA?
3. **Rules check:** Which of the 11 rules does it follow?
4. **What's missing:** Which rules does it break? Did it still work? Why?
5. **Steal the structure:** Write your own post with the same skeleton but your topic

This is how you develop pattern recognition. Do it 3x/week for a month and you'll instinctively write better hooks.

## Deliberate Practice

Each session uses neuroscience-backed techniques to maximize skill acquisition:

1. **Short pauses** — pause briefly between exercises so each attempt is distinct.

2. **Self-testing** — after writing a draft, score it yourself against the 11 rules before running `/linkedin-post review`.

3. **Recovery** — take a configured break after focused practice.

4. **Time boxes** — practice one module per session and choose a duration that fits the user's schedule.

5. **Consistency** — use a repeatable practice slot when the user wants one.

6. **Sustainable pacing** — do not schedule practice at the expense of configured rest constraints.

## Weekly Practice Schedule

| Day | Activity | Time | Practice cue |
|-----|----------|------|-------------------|
| **Sun** | Module 5: Deconstruct 1 top post | 15 min | Pause between each analysis point |
| **Mon** | Module 1: Write 5 hooks for this week's topic | 20 min | Brief pause between hooks |
| **Tue** | Module 2: Write the meat section | 20 min | Self-score before AI review |
| **Wed** | Module 3: Write CTA + first comment | 10 min | Pause between each CTA attempt |
| **Thu** | Full draft: combine Mon-Wed + run `/linkedin-post review` | 25 min | Self-review first, compare score vs AI |
| **Fri** | Module 4: Polish voice, publish, engage for 90 min (Golden Hour) | 90 min | Observe engagement patterns (learning from feedback) |
| **Sat** | Rest or Module 5: Deconstruct another post | 15 min | Rest = consolidation |

## Progress Tracking

After each published post, log:
```
Post: [title/topic]
Date: [date]
Format: [text/carousel/image]
Language: [en/he]
Impressions: [after 48h]
Comments: [count]
Saves: [count if visible]
Rules followed: [X/11]
What worked: [specific observation]
What to improve: [specific next step]
```

Over time, you'll see which patterns work for YOUR audience. That's the real training data.

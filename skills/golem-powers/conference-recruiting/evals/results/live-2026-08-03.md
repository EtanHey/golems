## Gaps found (v2 candidates)

1. Speaker-affiliation mining skipped when sponsor volume is high — make it an explicit
   opt-out, not a silent skip.
2. Model-pin gate: Agent spawns need explicit model pin (canon rule 5); also stagger to
   ≤3 concurrent dispatches — first run launched 5 at once.
3. Deep-link extraction fails on Ashby/JS boards — add ATS-API-first guidance (Greenhouse
   boards-api, Ashby posting API) to references.
4. **Profile-sourcing defect (subject correction, post-run):** Rule 3 "load profile from memory" let
   the run brief agents with "~5y mid-senior" from a stale brain_search snippet; the configured
   profile source says ~3 yrs. Level filter ran one notch high.
   Fix for v2: a configured profile source OVERRIDES memory snippets — brain_search
   is for preferences/history, while the profile source owns candidate claims.

# Draft a LinkedIn Post

Draft a post following Aviv Levi's 2026 algorithm guidelines. You finish and publish — this just gets you 80% there.

## Input

User provides a topic or angle. If not provided, run `/linkedin-post topic` first.

## Steps

### 1. Load Context

Read these before drafting:
- `linkedin-guidelines.md` — the 11 rules
- User's communication style: casual, Hebrew/English code-switching, brief, friendly

### 2. Choose Format

| Format | When to Use | Engagement |
|--------|-------------|------------|
| **Numbered list** | How-to, tips, lessons learned | High saves |
| **Story + lesson** | Personal experience, failure/success | High comments |
| **Contrarian take** | Challenge common belief | High comments |
| **Carousel/PDF** | Step-by-step guide, framework | Highest (6.6%) |

### 3. Draft Structure

Follow the template exactly:

```
[HOOK - 3 lines max]
Line 1: Surprising fact, number, or personal confession
Line 2: Why it matters or what changed
Line 3: Promise of what's coming ("Here's what I learned")

[BLANK LINE]

[MEAT - the value]
Each point on its own line
Max 12 words per sentence
Lots of whitespace
Specific numbers > vague claims
Personal experience > generic advice

[BLANK LINE]

[CTA - conversation starter]
Open-ended question
NOT "follow me" or "like this post"
Something that invites real discussion
```

### 4. Apply Rules Checklist

While drafting, verify:
- [ ] No external links in post body (Rule 3)
- [ ] All sentences under 12 words (Rule 4)
- [ ] Hook stops the scroll in 3 lines (Rule 10)
- [ ] Content is save-worthy (Rule 7)
- [ ] Authentic voice, not corporate (Rule 9)
- [ ] CTA invites discussion (Rule 10)
- [ ] Estimated read time: 30-60 seconds (Rule 1)

### 5. Mark Human Touch Points

Insert markers where Etan should add personal voice:

```
[YOUR TAKE: what did this feel like? add personal reaction here]
[YOUR NUMBER: insert actual metric from your experience]
[YOUR PHOTO: consider adding a real photo of your setup/screen]
```

### 6. First Comment Draft

Also draft the first comment (Rule 11):
```
First comment to post immediately after publishing:

"Want the full breakdown? DM me 'guide' and I'll send it."

OR

"Link to the full repo/article: [URL here]"
```

### 7. Output Format

```
## LinkedIn Post Draft

**Topic:** [topic name]
**Format:** [text / numbered list / carousel]
**Language:** [English / Hebrew]
**Estimated read time:** [X seconds]
**Target:** [saves / comments / both]

---

[THE ACTUAL POST DRAFT]

---

### First Comment
[comment to post right after publishing]

### Before Publishing Checklist
- [ ] Read it on your phone (mobile preview)
- [ ] Does the hook make YOU stop scrolling?
- [ ] Added personal touch where marked
- [ ] Blocked 90 min after posting for engagement (Rule 6)
- [ ] No links in post body
```

## Language Notes

- **English posts:** For global developer audience
- **Hebrew posts:** For Israeli tech community (higher engagement locally)
- **Code-switching:** Mixing is fine — it's authentic to Etan's voice
- Keep Hebrew casual (formality 2/10), no "corporate Hebrew"

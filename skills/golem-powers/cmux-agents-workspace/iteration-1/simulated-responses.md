## Qualitative findings

The simulated cases exercised three ecosystem-specific behaviors:

- install monitoring before telling the user it is safe to leave;
- broadcast useful context to every relevant agent instead of only storing it;
- salvage and respawn frozen work instead of absorbing implementation into the
  orchestrator's context.

The no-skill simulations reproduced the intended anti-patterns, while the
with-skill simulations applied the encoded workflow. Because the exercise was
self-graded and lacks runtime provenance, it may guide future cases but cannot
support a public performance claim.
